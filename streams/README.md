# CX Streams

This directory contains the master-level definition and navigation files for the **12 Autonomous CX architecture streams**.

Each stream is explicitly anchored to its corresponding **BootCamp**, which represents the learning and architecture theme for that capability domain.

## Standard Stream Structure

Each stream follows the same architecture pattern:

**APQC Process Area → CX Capability Area → BootCamp → Capability Scope → Example Platforms → Architecture Concerns → Autonomy Pattern**

The BootCamp is not a product-specific training label. It is the architectural learning theme through which the stream is explored across:

- Business capabilities
- Value streams and customer journeys
- Processes
- Data and intelligence
- Applications and platforms
- Technology
- AI and automation
- Integration
- Experience
- Governance
- Measurement and value realization

## Autonomous CX Autonomy Pattern

**Observe → Understand → Decide → Recommend → Act → Verify → Learn**

This pattern is applied consistently across all 12 streams while allowing each stream to define its own domain-specific capabilities, processes, data, AI and architecture concerns.
