# Reference Architectures

Reusable target-state and solution reference architectures for common Autonomous CX scenarios will be maintained here.

Representative patterns include customer 360 and identity resolution, omnichannel journey orchestration, lead-to-revenue, commerce and order experience, case management and autonomous service, subscription and recurring revenue, customer data and intelligence, digital self-service, conversational AI and agentic CX, event-driven integration, and customer consent/privacy/identity.
