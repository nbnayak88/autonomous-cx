# Standards

This area documents standards, methods, frameworks, and regulatory considerations relevant to Autonomous CX architecture.

Reference families include APQC Process Classification Framework, TOGAF, ArchiMate, BIZBOK, BABOK where business analysis is required, DAMA-DMBOK for data management, ISO/IEC 27001 and relevant security/privacy standards, accessibility and digital experience standards, and applicable jurisdictional consumer, privacy, identity, and records requirements.

Standards are reference points; architecture decisions remain contextual and evidence-based.
