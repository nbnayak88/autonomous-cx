# CX Ecosystem

The Autonomous CX ecosystem is platform-neutral.

SAP CX, Salesforce, Microsoft Dynamics, Adobe, ServiceNow, Zendesk, Shopify, Databricks, MuleSoft, Boomi, Kafka, and specialized CX providers are treated as ecosystem components that can support one or more business capabilities.

Products should be evaluated in the context of capability fit, process fit, data architecture, experience requirements, integration, security/privacy, operating model, economics, and strategic context.
