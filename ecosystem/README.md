# CX Ecosystem

The Autonomous CX ecosystem is platform-neutral.

SAP CX, Salesforce, Microsoft Dynamics, Adobe, ServiceNow, Zendesk, Shopify, Databricks, MuleSoft, Boomi, Kafka, and specialized providers are ecosystem components that can support one or more capabilities.

Products should be evaluated in the context of capability fit, process fit, data, experience, integration, security/privacy, operating model, economics, and strategic context.
